# Reserva ₿ Colombia

Iniciativa ciudadana: simulador de una Reserva Estratégica de Bitcoin para Colombia,
financiada con los remates de bienes de la SAE (Sociedad de Activos Especiales).

- Simulación DCA: 365 compras anuales con cifras públicas de la SAE
- Composición 80% BTC / 20% canasta de innovación (ETH, SOL, HYPE, otros)
- Módulo de rendimientos DeFi para planes sociales sin cobrar impuestos
- Comparación con EE. UU., Brasil (PL 4501/2024) y El Salvador

Sitio estático autocontenido (un solo `index.html`, sin dependencias ni build).
Ejercicio ciudadano de conciencia y simulación — no es asesoría financiera.
